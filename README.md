# Dynamic AI-Driven Bus Scheduling System

This project aims to develop a dynamic AI-driven scheduling system for urban bus transport that optimizes bus schedules based on real-time and historical passenger demand, traffic patterns, and carbon emissions.

## Features

- Predict passenger demand at stop-level granularity using historical data
- Analyze traffic patterns for real-time rerouting
- Calculate and optimize carbon footprint per route and time of operation
- Recommend dynamic schedules to balance load, efficiency, and sustainability

## Project Structure

- `data_ingestion/` - Modules for ingesting passenger, traffic, weather, and emission data
- `models/` - Predictive models for passenger demand and traffic analysis
- `optimization/` - Scheduling optimization algorithms
- `utils/` - Utility functions for carbon footprint calculation and data processing
- `app.py` - Main application entry point
